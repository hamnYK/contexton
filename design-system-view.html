디자인 시연용 · 새로고침하면 초기화됩니다.

‘지지’라는 관계 유형과 ‘그 관계 해석을 지지하는 의견’은 별개입니다. 현재 시안은 의견 작성자가 입장을 직접 선택하는 방식입니다.

온톨로지 구조는 글쓰기와 같은 오른쪽 슬라이드 패널로 열립니다. 데스크톱에서는 화면 너비의 75%, 800px 이하에서는 전체 너비를 사용하며 캔버스 화면만 왼쪽으로 이동합니다. 보기 드롭다운에서 지식 구조·캔버스 연결·온톨로지 정의를 선택합니다. 글쓰기와 온톨로지 구조는 한 번에 하나씩 표시하고, 전환해도 입력한 글쓰기 설정은 유지합니다. 각 패널의 닫기 버튼으로 캔버스로 돌아옵니다.

로그인하지 않은 상태로 시작하면 로그인·협업 탭을 먼저 엽니다. 로그인 전에는 슬라이드의 닫기 버튼이 비활성화되며, 로그인에 성공하면 닫기 버튼으로 캔버스에 진입합니다. 별도의 캔버스 중앙 로그인 안내는 표시하지 않습니다. 로그아웃하면 로그인 슬라이드가 다시 열리고 닫기가 비활성화됩니다. 작업 데이터는 지우지 않습니다. 로그인 세션이 유지되어 있으면 캔버스로 시작합니다. 개인 캔버스의 이름은 가입 시 로그인 ID로 입력한 이메일을 사용해 ‘이메일의 맥락’으로 표시합니다. 협업 캔버스에서는 해당 캔버스 이름을 표시합니다. 로그인·협업과 작업 백업·복원은 상단의 한 버튼으로 여는 슬라이드 패널에 모았습니다. 글쓰기와 같은 너비(데스크톱 75vw, 800px 이하 전체 너비)를 사용합니다. 로그인·협업 / 작업 백업·복원 두 탭을 전환하며, 파일 백업·복원에는 로그인이 필요하지 않습니다. 닫기 버튼으로 종료하고, 키보드 좌우 방향키와 Home·End로 탭을 이동할 수 있습니다.

상단 새 캔버스를 누르면 현재 캔버스를 보관하고 빈 캔버스를 엽니다. 노드가 있는 캔버스만 왼쪽 칩으로 표시합니다. 빈 캔버스는 칩이 생기지 않으며, 빈 상태에서 새 캔버스를 반복해서 눌러도 빈 항목이 쌓이지 않습니다. 칩은 처음 보관한 시각을 YYYY-MM-DD HH:mm:ss 형식으로 표시하고 다시 열거나 수정해도 시각을 유지합니다. 칩을 눌러 이전 캔버스로 돌아갈 수 있습니다. 칩 옆 삭제하기는 확인 후 해당 개인 캔버스의 이미지·연결·해석·글쓰기 결과를 삭제하며 되돌릴 수 없습니다. 협업 캔버스의 칩은 목록에서만 제거하고 서버의 공유 데이터는 유지합니다. 개인 캔버스 목록은 로그인 계정별로 이 브라우저에 저장되며, 다른 기기로 옮기려면 각 캔버스를 백업하세요.

05 — WRITING

가이드를 저장하고 AI에게 요청합니다.

1. API 세팅2. 가이드 설정3. 글쓰기 결과물

API 세팅

처음 선택되는 탭. 제공자·키·모델을 저장합니다. 설정 저장과 탭 전환은 생성을 시작하지 않습니다. 미저장 API 변경이 있으면 이전 설정으로 요청하지 않고 저장 안내를 표시합니다. 모델 조회 중 연결 정보 변경·설정 삭제 시 이전 요청을 취소하며, 늦은 응답은 새 설정의 목록·안내·로딩 상태를 바꾸지 않습니다.

가이드 설정

캔버스 전체의 노드·방향·해석·의견을 사용합니다. 선택 범위로 재료를 제한하지 않습니다. 작성 방향을 저장한 뒤 AI에게 글쓰기 요청을 실행합니다.

글쓰기 결과물

API 미설정 시 설정 안내만 표시합니다. 명시적 요청으로 글을 생성하며 취소·복사·TXT 다운로드를 제공합니다. 실패 시 이전 결과를 유지합니다.

자료나 설정 변경 후에는 가이드를 다시 저장합니다. AI에는 가이드 텍스트를 전달하며 원본 이미지는 보내지 않습니다. API 키는 탭 세션에만 보관하고 작업 백업에는 넣지 않습니다.

글쓰기 패널 동작 규칙
넓이와 전환데스크톱 75vw, 800px 이하 화면에서는 전체 너비. 오른쪽 슬라이드와 함께 캔버스 화면을 왼쪽으로 이동하되 노드 좌표는 유지합니다.
닫기닫기 버튼으로만 닫습니다. 캔버스 클릭·Esc·노드 선택으로 닫거나 다른 편집창으로 교체하지 않습니다. 연결 만들기는 비활성화합니다. 상단 버튼으로 온톨로지 구조 또는 로그인·협업 / 백업·복원 패널로 전환할 수 있으며 글쓰기 입력은 유지합니다.
접근성탭의 선택 상태를 전달합니다. 가이드에서 AI에게 글쓰기를 요청해 결과물로 전환하면 결과물 탭에 포커스를 옮겨 키보드 조작을 이어갑니다. 420px 이하에서는 Label 크기와 작은 간격으로 세 탭 제목을 한 줄에 표시합니다. 좌우 방향키와 Home·End로 이동하며, 동작 줄이기 설정에서는 슬라이드 애니메이션을 생략합니다.
06 — ONTOLOGY

정의와 실제 데이터를 함께 보여줍니다.

지식 구조

기본 보기. 실제 JSON-LD의 식별자와 연결로 이미지, 관계 해석, 의견, 반응, 작성자를 표시합니다. 전체 또는 연결별 범위를 고릅니다.

캔버스 연결

방향과 관계 이름을 보여주는 요약. 해석 대기는 중립색 점선으로 표시하고, 연결 이름을 선택하면 지식 구조로 이동합니다.

온톨로지 정의

RDF/OWL 어휘와 SHACL 파일에서 클래스·속성·제약을 읽습니다. 클래스별 데이터 수를 표시합니다. 제약 표시를 검증 완료로 표현하지 않습니다.

별도 대화상자로 열고 닫기 버튼으로 닫습니다. 유형은 색과 문자 라벨을 함께 사용합니다. 물리 기반 자동 배치를 사용하고 멈추기·시작을 제공합니다. 같은 두 항목의 복수·양방향 관계는 방향을 고려한 서로 다른 곡률로 분리합니다. 동작 줄이기 설정에서는 초기 배치 후 움직임을 멈춥니다. 항목은 캔버스 클릭 또는 키보드로 조작 가능한 항목 선택 목록으로 상세 확인하며, 시각화 배치가 원본 캔버스를 바꾸지 않습니다. JSON-LD 내보내기는 이 화면에 둡니다.

07 — WORKSPACE TOOLS

도구 이름은 실제 역할을 드러냅니다.

도구포함하는 기능
작업 백업·복원작업 백업, 백업 불러오기, 자동 저장 안내. 불러오기는 현재 작업 백업 후 교체이며 합치기가 아닙니다.
로그인·협업 / 협업 관리계정과 공유 캔버스 관리를 하나의 대화상자로 제공합니다. 공유 중에는 참여자·초대·동기화 상태를 먼저 표시합니다. 개인 온라인 사본은 펼침 영역에 둡니다. 공유 데이터와 개인 API 설정을 구분하고, 결과 읽기는 API 설정 없이도 허용합니다. 충돌 시 입력을 보존하고 백업 후 최신 내용 불러오기를 제공합니다.
작성자 설정데스크톱에서는 작업 이름 옆, 1000px 이하 화면에서는 상단 메뉴에 배치해 항상 접근할 수 있게 합니다. 이후 작성할 내용의 표시 이름을 변경합니다. 로그인·소유권 변경으로 표현하지 않습니다.
연결 만들기캔버스에서 시작·도착 노드를 차례로 선택합니다. 백업 패널에는 중복 연결 폼을 두지 않습니다.

백업은 이미지·관계·의견과 저장한 가이드·결과를 포함합니다. JSON-LD는 외부 지식 도구용 내보내기이며 작업 복원 형식과 구분합니다.

우리가 지키는 세 가지.

01

콘텐츠를 먼저.

이미지 전체를 보존하고, 장식은 줄입니다. 인터페이스는 생각을 읽는 데 필요한 만큼만 존재합니다.

02

판단의 주체를 분명히.

논리적 관계도 작성자의 해석입니다. 모든 관계에 작성자와 의견을 함께 표시합니다.

03

다른 관점에 열린 공간.

지지와 반대를 좋고 나쁨으로 색칠하지 않습니다. 서로 다른 해석을 나란히 읽을 수 있게 합니다.

캔버스 조작 원칙 — 기본 조작에는 모드 전환이 필요하지 않습니다. 노드 클릭은 선택과 편집, 노드 드래그는 해당 노드의 배치, 빈 공간 드래그는 화면 이동, 휠은 확대·축소입니다. Shift+클릭은 여러 항목의 선택을 조정하는 동작이며, 선택만으로 위치나 연결이 바뀌지 않습니다. Shift를 누른 동안에는 노드 이동을 막습니다. 이미지를 빈 캔버스에 놓으면 썸네일 노드를 즉시 생성하고 ‘노드 해석’ 패널을 엽니다. 출처와 해석을 입력한 뒤 ‘저장’을 누릅니다. 노드를 다시 선택하면 같은 패널이 열리고, 저장된 내용이 있으면 버튼을 ‘수정’으로 표시합니다. 기존 노드 위에 이미지를 놓으면 원래 노드를 유지하면서 새 노드와 연결을 함께 만듭니다. 기존 노드끼리는 상단 연결 만들기에서 두 노드를 차례로 선택합니다. 연결 만들기 직후 관계 계열·하위 관계 선택, 정의 작성, 다른 해석 추가, 저장 순으로 진행합니다. 저장된 링크는 클릭해서 다시 확인합니다. 노드 패널에는 연결 시작 버튼을 두지 않습니다. 노드 생성자만 출처·해석을 수정하거나 노드를 삭제할 수 있습니다. 다른 사람의 노드는 읽기 전용입니다. 삭제는 선택과 분리합니다. 로컬 모드는 실행 취소를 제공하고 협업 모드는 확인 후 삭제하며 되돌리기를 지원하지 않습니다. 협업 모드에서 노드·연결·의견의 작성자 권한을 서버에서도 검사합니다. Delete·Backspace는 캔버스에 포커스가 있을 때만 작동하며, 글쓰기 중에는 적용하지 않습니다. 다른 패널의 버튼이나 탭에 입력한 키가 뒤쪽 캔버스를 변경하지 않아야 합니다.
