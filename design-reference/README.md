# contexton 디자인 시스템 스타일

2026.09.15의 색상 토큰, 폰트, 여백과 공통 컴포넌트 스타일을 가져와 contexton의 이미지 노드·관계 해석·글쓰기·온톨로지·협업을 설명하는 뷰어로 구성합니다. 홈페이지·게임·워크숍 콘텐츠는 사용하지 않습니다.

원본 공통 CSS는 css/에, contexton 전용 시연 스타일은 contexton.css에 있습니다. 폰트는 라이선스와 함께 로컬 제공됩니다. 실제 작업실·사용자 가이드·뷰어는 theme.css의 공통 색상과 폰트를 사용합니다. 예시는 저장소나 외부 API에 접근하지 않습니다.
