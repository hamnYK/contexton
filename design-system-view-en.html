01

Natural interaction before explanation

Start with images

Drop an image on empty canvas space to create a node. Drop it on a node to create a connected node. There is no Add node menu.

Interpret beside the object

Click a node or link to open an editor pointing to it. Read and edit sources, definitions and interpretations in context.

Distinguish perspectives from facts

Relationships are authors' interpretations. Show comments and agreement/veto counts without presenting those counts as truth.

02

Color separates actions, selection and relationships

Coral marks primary actions; sky tones separate workspace surfaces. A dark blue outline marks selection. Relationship categories and states also have text labels.

Editor guide lines are neutral dashed lines. Actual links use solid lines and filled triangular arrowheads.

03

Readable headings and comfortable body text

SUITE is used for Korean headings, Space Grotesk for English headings and Pretendard for body text and inputs. Fonts are local assets. Supporting text and statuses remain readable.

04

Leave space between input and action

Spacing

8px between label and input, 16px between fields and before Save, 24px inside cards. Controls use 4px corners and cards use 6px corners.

States & accessibility

Distinguish selection, focus, saving and read-only states. Use at least 44px touch targets. Deletion is a separate action from selection.

07

Write from canvas context

Turn the whole canvas's image interpretations, directed links, definitions and comments into a writing guide. Guide creation is distinct from automatic ontology reasoning and AI generation.

Configure your writing AI

Configure provider, API key and model. This example does not accept real API keys.

API settings stay in the user's browser and are excluded from shared data and backups.

Materials & writing direction

Read the whole network, not just selected items. Set purpose, audience, format, perspective and narrative order, save the guide, then ask AI to write.

Writing result

Complete AI configuration in the API settings tab first.

Generate only on explicit request. Failures/cancellation retain previous results. Support copy and TXT download.

The right drawer is 75vw on desktop and full width at 800px or below. Shift the viewport without moving nodes. Use Close to exit. Resave the guide after changing materials.

08

The structure of accumulated knowledge

Physics-based layout

Use separate curves for multiple/reverse relationships. Let users pause/resume layout. Reduced-motion preference stops movement after initial layout.

Distinguish standards from validation

Display RDF/OWL vocabulary and SHACL constraints. JSON-LD export is administrator-only with online verification. Displaying constraints does not imply validation or reasoning has run.

Narrative order is presentation order, distinct from link direction. AI input combines the same ontology vocabulary with the saved structured network. Distinguish guides, snapshots, actual input and generated results without inventing missing provenance. Ontology uses the same drawer pattern with a View dropdown and Close button. Its layout never changes the original canvas.

09

Private settings and shared context

Sign in & collaborate

Open sign-in first for guests and disable Close until sign-in. Shared spaces display participants, invitations and sync status.

New canvas

Only canvases with nodes become timestamp chips. Do not duplicate empty canvases. Personal lists are stored per account in the browser.

Backup & restore

Provide Backup & restore as a separate Account & workspace tab. Preserve images, relationships, comments, guides and results. Back up before restoring. Exclude API settings.

Other authors' node content is read-only. Shared mode also checks authorship on the server. Preserve input during conflicts and explain the next action.

Canvas list & workspace

After sign-in, show an image-drop hint on empty canvases. Hide it before sign-in and once nodes exist. It must not intercept clicks or drags.

Desktop separates the left canvas list from the workspace. At 800px or below, the list becomes a horizontal row above the canvas so it does not cover interactions.

Account & management layout and states

Donate is a secondary button before New canvas. Open a modal up to 600px wide, dismissed only by Close. Outside clicks and Esc do not dismiss it. Keep focus inside and return focus to the trigger after closing. Use shared colors, heading fonts and 44px buttons.

Use Account & workspace for both the top button and drawer title. Order tabs as Sign in & collaborate, Backup & restore, then administrator-only Users and Content. Disable Close before sign-in.

Account & sign-out

Group the signed-in label, email and bordered Sign out button in a card. Use 44px minimum button height, 20px card padding and 16px element gaps.

Management lists

Align notices, tools and lists to the same centered width. Group All users and Refresh list with 12px gaps. Distinguish missing setup, empty lists and failures. Confirm deletion and allow hidden items to be restored.

Permission states

Enable the design-system link and JSON-LD export only for administrators. Hide administrator tabs for others. Show this document after online administrator verification. This UI restriction does not make static source files private.

The footer shows storage status, zoom, node/link counts and © 2025 WORFLOGY Inc. All rights reserved. Move copyright to another row on small screens. API settings are excluded from server storage, sharing and backups.

Author display

The default author is the login email, including on new canvases. Custom names and existing records are retained. Only your own nodes, interpretations and comments display (me); other participants see the stored name. Ownership IDs determine identity and editing rights, not names. Unverified older records do not receive (me).

Interface language

Provide two language buttons in the header with color and aria-pressed selection states. Translate interface text and accessibility labels while preserving user data and option values. Wrap long English labels to prevent mobile overflow.
