02 — Images & nodes

Drop an image to create a node.

  1. Drag an image onto empty canvas space.

    A thumbnail node appears immediately. PNG, JPEG and WebP images up to 2MB each are supported.

  2. Add a source and interpretation in Node interpretation.

    Enter the image source (up to 500 characters) and interpretation (up to 200 characters), then save.

  3. Click the node again to edit.

    If a source or interpretation is already saved, the button reads Update.

Dropping a new image onto an existing node preserves the original image and creates a new node nearby with a directed link from the original. Fill in the new node first; click the link later to interpret it.

Editing & deletion

Local mode checks the browser identity; shared mode checks the account ID for node editing and deletion. Older nodes with unknown creators are read-only. Changing a display name does not change ownership.

Select an item and use Delete in the toolbar. Deleting a node also removes its links, while other nodes remain. Local deletions can be undone. Shared deletions require confirmation and cannot be undone. Delete/Backspace shortcuts apply only when the canvas has focus, not while the writing panel is open.

03 — Links & interpretations

Keep multiple interpretations on one link.

  1. Use Create link to connect existing nodes.

    Click the source and target nodes in order. Links are directed.

  2. Choose a relationship family and specific type.

    Define the relationship in the editor beside the link. Add several interpretations, then save them together.

  3. Comment on saved interpretations.

    Comments appear in creation order. Agree or veto each comment, then change or remove your reaction if needed.

Deleting a comment also removes its reactions, but not the interpretation or node. To delete the link itself, select it on the canvas and use Delete in the toolbar.

A relationship named Cause is still a proposed interpretation. The ontology does not establish causality as fact.

New canvas saves the current canvas and opens an empty one. Only canvases containing nodes become chips. Repeatedly creating an empty canvas adds no chips. Labels use the first saved timestamp, YYYY-MM-DD HH:mm:ss, and remain stable. Click a chip to return. Deleting a personal canvas permanently removes its local contents after confirmation; removing a shared chip only removes the list entry. Lists are stored per account in this browser. Back up each canvas to move devices.

04 — AI writing

Write from canvas context

The top button opens a wide drawer from the right and shifts the canvas left. Closing and reopening preserves input. Close this panel before using backup/restore or creating links.

1. API settings2. Writing guide3. Writing result
  1. API settings

    Start with API settings. Choose Gemini, OpenAI, Claude or a local OpenAI-compatible API. Enter the key and model, then save. Load models or enter an ID manually. Changing connection details cancels an in-flight model request; load the list again. Local APIs also require a server URL.

    Save changed provider, key or model settings before generating. Keys stay in this tab's session and are excluded from backups. Saving settings does not generate text.

  2. Writing guide

    The whole canvas is included, regardless of selection: nodes, link directions, interpretations and comments, including disconnected nodes. Choose genre, purpose, audience, format, length, perspective and principles, then save the guide.

    Save again after changing materials or settings. AI receives the saved guide text; original images are not sent.

  3. Writing result

    Use Ask AI to write or Generate text explicitly. New generation is blocked until API setup is complete, but saved/shared results remain readable. Opening a tab does not call AI. Requesting text from the guide moves keyboard focus to the result tab.

    Cancel while generating. Failed or cancelled requests retain the previous result. Copy the result or download it as TXT.

Usage is billed to your provider account. If direct browser access is blocked, check provider or local-server CORS settings. Review generated text and sources before use.

Narrative order & generation evidence

Let AI choose the structure or order nodes manually. Move earlier/later changes presentation order only, not link direction, chronology or causality. Save the guide after changing it.

AI receives the same vocabulary semantics shown in the ontology definitions plus the saved network of nodes, links, interpretations, comments and reactions. Targets and authors are distinguished; uninterpreted links and disconnected materials remain. Sending these rules does not semantically validate the output.

Knowledge structure includes saved guides, material snapshots, actual AI input, generating model and results. Resaving a guide preserves previous result prompts. If an older structured snapshot is missing, only a reference is shown. Unrecorded requesters and paragraph-level evidence are not inferred. These links do not guarantee factual accuracy.

05 — Ontology structure

Explore the knowledge you have built.

Open Ontology structure to see the actual JSON-LD graph. Select an item to inspect details, identifiers and applicable constraints.

Ontology opens in a right drawer like writing: 75vw on desktop, full width at 800px or below. Only the viewport shifts. Choose Knowledge structure, Canvas connections or Ontology definitions. Writing and ontology open one at a time; writing inputs are retained. Use Close to return.

Knowledge structure

Explore images, links, interpretations, relationship types, comments, reactions and authors. View the whole graph or one link.

Canvas connections

Inspect image-to-image direction and interpretation. Dashed links await interpretation. Click a link label to explore its knowledge structure.

Ontology definitions

Inspect RDF/OWL classes and properties, SHACL constraints, class counts and property usage.

Physics adjusts spacing automatically. Pause/resume layout, zoom, pan and drag items. Multiple and reverse relations use separate curves. The item selector provides keyboard access. Graph layout does not alter the canvas. JSON-LD export is enabled only for administrators and requires online verification. Backup/restore is separate.

Displaying SHACL constraints is not the same as executing validation. This screen does not show automated reasoning results or replay change history.

06 — Backups & authors

Keep backups of your work.

Guests start in Sign in & collaborate with Close disabled. After signing in, Close opens access to the canvas. Sign-out reopens this panel without deleting work. Sign out is in the account card. Retained sessions start on the canvas. Personal headings use the login email; shared canvases use their names. Account & workspace contains sign-in/collaboration and backup/restore tabs in a 75vw drawer (full width at 800px). File backups do not require sign-in. Use Close to exit and arrow/Home/End keys to navigate tabs.

07 — Collaboration & online storage

Work together on the same canvas.

  1. Open Account & workspace and sign in under Sign in & collaborate.

    Register by email and verify the account. Signing in alone does not share your work.

  2. Open Start collaborating with this work.

    Name and create a shared copy. You own the copied items; previous author labels remain. Existing reactions are marked as unverified history. The original local workspace remains.

  3. Share an invitation code.

    Create a code and send it directly to chosen participants. They sign in and join with the code. It expires after 7 days and can be revoked or replaced by the owner.

  4. Drop images and save interpretations and comments.

    Item-level changes save automatically to the database and appear for other participants. Check server save/pending/error states in the footer. Incoming changes wait while you are editing.

Shared dataPrivate information
Images, node positions, sources, interpretations, directed links, definitions, comments, reactions, saved guides and writing resultsAPI provider, model, key, server URL, authentication tokens, current selection and zoom

A result's model name records provenance. Others cannot use your API configuration. Shared results remain readable without API setup, but new generation requires your own settings.

Permissions & conflicts

Node interpretation editing/deletion, link deletion and comment deletion require authorship. Participants can position nodes and add images, links, interpretations and comments. Deleting a node also deletes its links and their contents. Shared deletions require confirmation and cannot be undone.

Concurrent edits to the same item are not silently overwritten. Your changes are preserved with a notice. Back up your edits and load the latest version to compare. Edits to different items can merge. Keystrokes and mouse cursors are not broadcast live.

Unsent edits are kept separately in this browser after connection failure. Retry saving or reopen the same canvas in the same tab/account to recover. Download a backup before fully closing a tab with pending changes. Returning to local work or signing out restores the previous local canvas.

Personal online copies

Expand Personal online copies to save/load snapshots. Users can access their own copies. This is not automatic sync; each save creates a new copy. The most recent 50 appear. Ordinary users have no delete button; administrators can hide/delete copies in Content.

Canvas list & workspace

Desktop separates the left canvas list from the workspace. At 800px or below, the list becomes a horizontal row above the canvas so it does not cover interactions.

Administrator tools

Administrators see Users and Content after Backup & restore. Inspect online content by user and hide/delete shared canvases, shared results and personal copies. Hiding is reversible; deletion is permanent. Local-only and downloaded copies are outside this management scope.

Design-system access & storage status

Donate

Open Donate before New canvas for donation information. Only the last three account digits are shown. Account copying, transfer links and QR codes are not provided. Online donations are being prepared. Only Close dismisses the modal. Donations are optional.

The design-system link requires verified administrator access for worflogy@gmail.com. It is disabled for guests and other users. The user guide is public.

Local means stored in this browser. Signing in does not upload work. Save personal online copies explicitly; shared canvases sync changes to the server. Check the footer status.

Administrators can hide, restore or delete online content, but cannot delete or suspend accounts through this interface. Image files may remain after content deletion to preserve reused images.

Author display

The default author is the login email, including on new canvases. Custom names and existing records are retained. Only your own nodes, interpretations and comments display (me); other participants see the stored name. Ownership IDs determine identity and editing rights, not names. Unverified older records do not receive (me).

Interface language

Use the Korean/English buttons at the top to switch the interface. Unsaved input and canvas data are retained. User contributions and existing AI results are not automatically translated. New AI requests from the English interface ask for English output.
